DaRT-Python-Edition ( DayZ Remote Tool Python Edition )

программное обеспечение предназначенное для удалённого администрирования через Rcon (Remote Console) протокол серверов DayZ Standalone, полностью свободное и поставляется как есть.

Автономный инструмент для Windows и Linux через командную строку ( CLI )

Работает по принципу скачал и запустил

Инструмент имеет как английский так и русский язык

настройка сервера для подключения осуществляется как через файл settings.json (создаваться автоматически при первом запуске), так и через интерфейс командной строки.

программное обеспечение полностью свободное и разрабатывалось с целью ознакомления автора с возможностями и сложностями разработки.
